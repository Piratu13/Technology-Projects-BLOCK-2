## 🧠 5. Reflection Questions

### 5.1 What would happen if two PCs had the same IP address?

When two PCs on the same network use the same IP address, an IP address conflict occurs. This can cause communication problems because the network may not reliably identify which PC should receive the data.

### 5.2 Why do we use a switch instead of directly connecting PCs together?

We use a switch because it allows multiple PCs to connect and communicate within the same LAN. Without a switch, connecting several PCs directly would require more cables and network connections. A switch makes the network easier to expand and forwards data to the appropriate connected device. In a larger university network, switches can also connect to routers to communicate with other networks.

### 5.3 What does the subnet mask 255.255.255.0 indicate?

The subnet mask 255.255.255.0 tells a computer how to divide an IP address into two parts: the network portion and the host portion. The first three octets (24 bits) identify the network, while the last octet (8 bits) identifies the host within that network. This helps computers determine whether another device is on the same local network.
