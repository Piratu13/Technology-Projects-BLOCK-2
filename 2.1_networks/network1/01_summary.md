## 📘 1. Summary of the Task
Describe the purpose of this activity in your own words:  
- What is the goal of the lab?  
- What network are you expected to create?

This project involves creating a small Local Area Network (LAN) for five computers in a university's Admin Building using Cisco Packet Tracer.

All five PCs are connected to a central switch, and each PC is assigned a unique static IP address manually.

The purpose of the project is to allow the computers to communicate within the same LAN and test their connectivity using the ping command. The network does not include a router or connections to other LANs.
