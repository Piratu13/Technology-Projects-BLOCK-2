
## 🗺️ 2. Network Topology Setup

### 2.1 Description  
Explain how you built the network topology (devices, cabling, layout).
I created a small Local Area Network (LAN) in Cisco Packet Tracer using one Cisco 2960 switch, one server, and three PCs (PC0, PC1, and PC2).

I connected all devices to the central switch using Copper Straight-Through Ethernet cables. The switch allows the devices to communicate within the same LAN.

I also configured the server with a static IP address of `192.168.2.2`, a subnet mask of `255.255.255.0`, and a default gateway of `192.168.2.1`.

The server will be used to provide DHCP and DNS services to the three PCs.
