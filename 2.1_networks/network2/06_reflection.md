
## 🧠 6. Reflection

Answer in full sentences:

1. What are the advantages of DHCP over static IP assignment?
The main advantage of DHCP over static IP assignment is that DHCP automatically assigns IP addresses and other network settings to devices, instead of requiring manual configuration.

This saves time, reduces configuration errors, and makes it easier to manage networks with many computers.

2. How does DNS improve usability in a network?
DNS improves usability by allowing users to access devices and services using human-readable names instead of remembering numerical IP addresses.

The DNS server translates these names into IP addresses, making network communication easier and more convenient for users.

3. What would happen if the DHCP server went offline?
If the DHCP server went offline, new devices would not be able to obtain IP addresses automatically.

Devices that already have valid DHCP leases could continue using their assigned IP addresses temporarily. However, they would be unable to renew their leases until the DHCP server became available again.
