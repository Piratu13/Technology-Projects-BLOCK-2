
## 📘 1. Objective (In Your Own Words)
Briefly describe the purpose of this lab.  
What were you trying to achieve?
---

The objective of this project is to create a small Local Area Network (LAN) in Cisco Packet Tracer using three PCs, one switch, and one server.

The server will be configured to provide two network services: DHCP (Dynamic Host Configuration Protocol) and DNS (Domain Name System).

DHCP will automatically assign IP addresses to the PCs instead of configuring each address manually. DNS will allow the PCs to communicate using hostnames instead of IP addresses.

The network will be tested to verify that the PCs receive their IP addresses automatically and can communicate using the configured DNS names.
